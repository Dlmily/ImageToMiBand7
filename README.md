# 小米手环7图像转换工具
在两年前就已经有人发了电脑端的这个工具，但迟迟不见有手机端的，虽然有一些人的确找到了解决方案，但是目前网络上的转换工具鱼龙混杂，一些萌新根本搞不懂，现在的情形非常需要一个手机端转换工具，于是就有了本帖。
与电脑端的不同，我们这个工具完全依赖终端进行操作，千万不要感觉麻烦，非常简单，接下来进行详细教程：
---
## 教程

### 1. 安装 Termux

首先你需要一个 [Termux](https://github.com/termux/termux-app/releases/download/v0.118.1/termux-app_v0.118.1+github-debug_arm64-v8a.apk)（点击下载即可）。

### 2. 给予 Termux 存储权限

安装完毕之后，给予 Termux 存储权限，命令为：

```bash
termux-setup-storage
```

接着你会发现它停在了这里：`Do you want to continue? (y/n)`，你只需要输入 `y` 并回车即可。

### 3. 复制图片到工作目录

接下来请前往自己的 MT 管理器，找到 `/storage/Pictures/` 这个路径（不同手机的可能有点不一样，这里不予区分教程，网上一抓一大把），你将会看到一堆文件夹，当然你要选择进行转换的图像也在这里面，接下来你只需要耐心的找，找到之后长按图像文件，把图像文件从这里复制到下载的文件所处的目录中。

### 4. 安装依赖并运行转换

完成了这一切之后你就可以返回终端输入下载的文件所处路径了：

```bash
cd +空格+复制的目录
apt update && apt upgrade
pkg install python
pkg install python-pillow
```

> **注：** 单次转换中，下载的 `4.py` 文件和需要转换格式的图片要处在同一目录下！

## 参数说明

| 参数 | 用途 | 示例 |
|------|------|------|
| `-b` | 批量转换指定目录中的图片 | `-b` |
| `-s` | 设置图片的最大宽度或高度；超过限制时会按比例缩放 | `-s 100` |
| `-c` | 设置颜色压缩数量，范围为 2 到 256；数值越小，颜色越少，文件通常越小，但可能出现色差 | `-c 256` |
| `-o` | 指定单张图片的输出文件名 | `-o result.png` |
| `--rle` | 强制使用 RLE 游程压缩，适合颜色块和重复像素较多的图片 | `--rle` |
| `--no-rle` | 强制关闭 RLE，使用普通调色板格式 | `--no-rle` |

> **注：** 携带 `--rle`、`--no-rle` 参数时，不使用自动择优。

**推荐：**

```bash
python 4.py {目录} -b -s 200 -c 128
```
